# Contributing

Open one pull request per entry. Small pull requests are easy to review.

## What goes in

An entry is a finding about how an AI answer engine, an AI crawler or a coding agent finds, reads or names a site, or about how to measure that, or about programmatic SEO.

Include it when all of these are true:

- It has a number or a test you can repeat, not only advice.
- The source is public and the link opens without a login.
- You read the source yourself and the number is on the page.

Leave it out when the source is a list of tips with no method, a paid report behind a form, or a tool's own marketing page.

## Entry format

```
- [Title of the source](https://example.com) (paper) - One plain sentence with the number.
```

- Kind is one of: paper, vendor, official docs, practitioner, forum, research report.
- Mark a source as vendor if its author sells in this field or runs the platform it measures.
- Put the entry in the right section, in alphabetical order by title.
- End the sentence with a period. Keep it to one sentence.
- If your finding conflicts with an entry already listed, add it and say so in the sentence.

## In the pull request

Give the link, the page or table where the number appears, and the date you read it. One or two lines are enough.

## Fixing an entry

If a link is dead or a number is wrong, open a pull request with the fix and the source. Dead links are removed.
